# SOLTURI · Campanhas 2026

Painel das campanhas **Bateu Levou** (mensal) e **High Ticket** (semestral).
Arquivo único e estático: todos os dados já estão dentro do `index.html`.

## Publicar no GitHub Pages (primeira vez)

1. Em https://github.com, clique em **New repository**, dê um nome (ex.: `solturi-campanhas`) e crie.
2. **Add file → Upload files** e arraste os arquivos desta pasta (soltos, não a pasta).
3. **Commit changes**.
4. **Settings → Pages** → Source: **Deploy from a branch**, Branch: **main**, pasta **/ (root)** → **Save**.
5. Em 1 a 2 minutos o link aparece no topo: `https://SEU-USUARIO.github.io/solturi-campanhas/`

## Atualizar os dados

**Add file → Upload files**, envie o novo `index.html` por cima do anterior e **Commit changes**.
Em 1 ou 2 minutos o link já mostra os dados novos (se não, recarregue com Ctrl+F5 / Cmd+Shift+R).
O link nunca muda.

## Privacidade

O painel contém nomes de representantes e valores de faturamento. Em contas gratuitas,
o GitHub Pages só funciona com repositório **público**: qualquer pessoa com o link abre a página.
A página está marcada para não ser indexada pelo Google, mas isso não é proteção de acesso.
